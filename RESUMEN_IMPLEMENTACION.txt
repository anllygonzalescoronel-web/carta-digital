1. CLIENTE HACE PEDIDO
   └─ Selecciona: tipo_comprobante, tipo_documento, numero_documento

2. SISTEMA VALIDA
   └─ ✅ Documento cumple formato requerido

3. SISTEMA REGISTRA PEDIDO
   └─ INSERT INTO pedidos (tipo_comprobante, tipo_documento, numero_documento, ...)

4. SISTEMA CREA COMPROBANTE
   ├─ IF driver = 'native':
   │  └─ registrarComprobanteElectronicoDesdePedido()
   └─ IF driver = 'nubefact':
      └─ emitirComprobanteNubefactUnificado()

5. SISTEMA REGISTRA EN BD UNIFICADA
   └─ INSERT INTO facturacion_comprobantes (numero_comprobante, estado, ...)

6. SISTEMA ENVÍA A AUTORIDAD
   ├─ IF SUNAT: enviarComprobanteSunatNativo()
   └─ IF NubeFacT: API responde inmediatamente

7. SISTEMA ACTUALIZA ESTADO
   ├─ UPDATE pedidos SET facturacion_estado = 'aceptado'
   └─ UPDATE facturacion_comprobantes SET estado = 'aceptado'

8. CLIENTE RECIBE RESPUESTA
   └─ {ok: true, comprobante: {numero, pdf, estado}}

  ✓ Contraseña Certificado
  ✓ Modo SUNAT (demo|beta|prod)
  ✓ Serie Boleta (ej: B001)
  ✓ Serie Factura (ej: F001)

  ✓ RUTA API (copiar de NubeFacT)
  ✓ TOKEN (copiar de NubeFacT)
  ✓ Serie Boleta (ej: BBB1)
  ✓ Serie Factura (ej: FFF1, opcional)
