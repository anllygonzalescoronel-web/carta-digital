⌨️ Instalación por Terminal

🐧

Linux / Mac

Usa el script bash automático para instalación rápida desde terminal.

cd /ruta/a/carta-digital/installer chmod +x install.sh ./install.sh
📥 Descargar install.sh
🪟

Windows

Utiliza el batch file para instalación automatizada. Requiere CMD como admin.

cd C:\ruta\a\carta-digital\installer install.bat
📥 Descargar install.bat
ℹ️ Requisitos CLI:
  • PHP disponible en PATH
  • MySQL disponible en PATH
  • Windows: Ejecutar CMD como Administrador
  • Linux/Mac: Permisos de ejecución (se otorgan automáticamente)
