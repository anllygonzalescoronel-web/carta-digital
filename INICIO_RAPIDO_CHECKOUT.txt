# 🚀 INICIO RÁPIDO: Checkout APIPERU

**¿Qué se acaba de implementar?**

Un sistema completo de checkout multi-paso que permite a tus clientes:
1. Seleccionar tipo de comprobante (Boleta/Factura)
2. Validar su DNI/RUC automáticamente via APIPERU
3. Confirmar datos de entrega
4. Pagar (Efectivo, Tarjeta, Yape, PLIN)

---

## ⏱️ 5 PASOS PARA ACTIVAR (5 MINUTOS)

### 1️⃣ Obtener Token APIPERU (GRATIS)

```
1. Ir a: https://apiperu.dev/
2. Click "Registrarse" → Crear cuenta
3. Completar formulario
4. Confirmar email
5. Login → Ir a "Cuenta" o "API"
6. Copiar tu TOKEN (ejemplo: abcd1234efgh5678...)
```

**¿Es gratis?** 
- ✅ Sí, incluye 100 consultas/mes
- 💰 Planes pagos para más consultas

### 2️⃣ Configurar Token en Admin (30 SEGUNDOS)

```
1. Entrar a: /admin/ → Configuración
2. Bajar hasta: "APIPERU - Validación RENIEC/RUC"
3. Campo: "Token APIPERU" → Pegar token
4. Marcar: ☑️ Habilitar validación
5. Click: GUARDAR CONFIGURACIÓN
```

### 3️⃣ Verificar Instalación (1 MINUTO)

```bash
# Terminal / CMD:
cd C:\laragon\www\carta-digital
php setup_apiperu.php

# Resultado esperado:
# ✅ Agregada configuración: apiperu_token
# ✅ Agregada configuración: apiperu_habilitado
# ✅ Configuración APIPERU agregada
```

**Si falla:** Verifica que la carpeta tenga permisos `755`

### 4️⃣ Probar en Navegador (2 MINUTOS)

```
1. Abrir tu web: http://localhost/carta-digital/ (o tu dominio)
2. Agregar producto al carrito
3. Click botón "Continuar" (carrito)
4. Se abre MODAL de checkout (pantalla nueva)
5. Seleccionar "Boleta"
6. Click "Siguiente"
7. Ingresar DNI: 12345678 (o DNI válido)
8. Click "Consultar"
9. ✅ Datos se auto-llenan!
10. Completar email, teléfono
11. Seleccionar "Recojo"
12. Click "Siguiente"
13. Seleccionar método pago
14. Confirmar pedido
15. ✅ Pedido completado!
```

### 5️⃣ Listo! 🎉

Tu checkout está 100% operativo. Los clientes pueden:
- ✅ Ingresar DNI → Se valida automáticamente en APIPERU
- ✅ Ver nombre completo + información personal autollenada
- ✅ Seleccionar tipo de entrega (recojo o delivery)
- ✅ Pagar por múltiples métodos
- ✅ Ver confirmación del pedido

## ❓ Preguntas Frecuentes

### ❓ "¿Cuántas consultas APIPERU puedo hacer?"
- **Free:** 100 consultas/mes
- **Pro:** Planes de pago desde $9/mes
- **Plus:** Consultas ilimitadas

👉 Ver: https://apiperu.dev/

### ❓ "¿Funciona sin Culqi?"
**Sí!** El cliente puede pagar en efectivo. Culqi es opcional.
- Efectivo: Checkout funciona 100% (sin Culqi)
- Tarjeta/Yape/PLIN: Requiere Culqi (configurar en Admin)

### ❓ "¿Qué pasa si hay error en APIPERU?"
- Mensaje amable: "Error consultando documento"
- Usuario puede reintentar
- Sistema sigue funcionando (permite entrada manual)

### ❓ "¿Puedo usar Factura sin Boleta?"
**Sí**, pero recomendamos habilitar ambas. En Admin → Configuración:
- `facturacion_driver_activo`: Elige "native" (SUNAT) o "nubefact"
- `facturacion_modo_hibrido`: Marca para permitir ambas en paralelo

### ❓ "¿El cliente ve su nombre llenado automáticamente?"
**Sí!** Después de validar DNI:
1. Usuario ingresa DNI "12345678"
2. Click "Consultar"  
3. Sistema consulta APIPERU → retorna "JUAN GARCÍA LÓPEZ"
4. Campo "Nombre Completo" se auto-llena
5. Usuario solo ingresa email y teléfono (más rápido!)

## 🛠️ Solución Rápida de Problemas

### 🔴 Problema: "El botón 'Continuar' no abre el modal"

**Solución:**
```
1. F12 → Console
2. Ejecutar: window.checkout.mostrarModal()
3. Si abre → está funcionando (verificar HTML)
4. Si error → revisión CSS (checkout-apiperu.css)
```

### 🔴 Problema: "La consulta APIPERU retorna error 401"

**Solución:**
```
Token inválido. Pasos:
1. Ir a https://apiperu.dev/ → Tu cuenta
2. Copiar token nuevo (verificar NO tenga espacios)
3. Admin → Configuración → APIPERU Token → Pegar
4. Guardar
5. Reintentar
```

### 🔴 Problema: "Culqi dice 'Formulario no inicializado'"

**Solución:**
```
1. Verificar Admin → Configuración → Culqi
   - Llave pública: pk_test_... (correcta)
   - Llave secreta: sk_test_... (correcta)
2. Guardar
3. Recargar página
4. Reintentar pago
```
